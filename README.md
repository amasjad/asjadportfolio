## 🚀 How to Host for FREE on GitHub Pages (Takes 2 Minutes)

You can host this directly on GitHub without installing any software:

### Step 1: Create a GitHub Repository
1. Log into your account on [github.com](https://github.com).
2. In the top-right corner, click the **`+`** icon and select **New repository**.
3. Choose a Repository name:
   - **Option A (Personal domain format - Recommended):** `<your-github-username>.github.io`
     *(Example: if your username is `asjad`, name the repo `asjad.github.io`)*
   - **Option B (Project format):** `portfolio`
4. Set the repository to **Public**.
5. Check **Add a README file** (or leave it unchecked).
6. Click **Create repository**.

### Step 2: Upload Your Files
1. On your new repository page, click the **Add file** button and choose **Upload files**.
2. Open this folder on your desktop:  
   `Desktop\Antigravity stuffs\portfolio`
3. Select and drag **ALL** files into GitHub:
   - `index.html`
   - `style.css`
   - `script.js`
   - `resume.pdf`
   - `profile.jpg`
   - `logo.png`
4. Scroll down, write a commit message (e.g., `Initial portfolio launch`), and click **Commit changes**.

### Step 3: Turn on GitHub Pages
1. In your repository, click the **Settings** tab (gear icon at the top).
2. In the left sidebar, click **Pages** (under the "Code and automation" section).
3. Under **Build and deployment** > **Source**, select **Deploy from a branch**.
4. Under **Branch**, choose **`main`** (or `master`) and folder **`/ (root)`**.
5. Click **Save**.

### Step 4: Your Live URL!
Within 1 to 2 minutes, refresh the GitHub Pages settings page. You will see a banner:
> **"Your site is live at `https://<your-username>.github.io/`"**
